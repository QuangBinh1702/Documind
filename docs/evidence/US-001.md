## Ghi chú cho báo cáo

**Quyết định:** cách lập chỉ mục từ khoá cho tiếng Việt — xem
`docs/decisions/0001-truy-xuat-tu-khoa-tieng-viet.md`. Đặc tả ban đầu sai và
đã được sửa dựa trên số đo thật.

**Hai cạm bẫy phát hiện khi kiểm chứng, cần nhớ khi viết mã:**

1. **`alembic.ini` phải thuần ASCII.** Alembic đọc file này với
   `encoding="locale"` (cp1252 trên Windows), nên comment tiếng Việt gây
   `UnicodeDecodeError`. Ghi chú tiếng Việt để trong `env.py` hoặc file
   migration — cả hai đều đọc bằng UTF-8.
2. **`substring` của SQL đánh chỉ số từ 1, slicing của Python từ 0.** Khi kiểm
   tra INV-1 bằng SQL phải viết `substring(full_text from char_start + 1 for
   char_end - char_start)`. Quên `+ 1` thì lệch một ký tự và test vẫn "gần
   đúng" — dạng lỗi khó thấy nhất.
